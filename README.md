# E-Commerce Delivery Analytics Dashboard
E-Commerce Delivery Analytics project using SQL and Power BI to analyze revenue, customer behavior, product categories, delivery performance, and refunds.
E-Commerce Delivery Analytics

Tools: SQL, Power BI, DAX

Objective: Analyze platform performance, product categories, customer behavior, revenue, delivery, and refund metrics.

Key Insights:

Swiggy Instamart had the highest revenue.
Personal Care had the highest revenue and AOV.
Platform performance was relatively similar.
Category order volumes were similar despite large revenue differences.
Refund rates were around 46% across platforms.
